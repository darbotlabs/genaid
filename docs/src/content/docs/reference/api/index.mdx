GenAID runs in a (slightly modified) Node.JS environment where additional globals have been added.
This environment is configured by the [cli](/genaid/reference/cli).
Therefore, in order to run a GenAID in a "vanialla" Node.JS process, you will need to the
**Node.JS `run` API**. This API loads and executes a GenAID script in a separate worker thread.

This page describes how to import and use the GenAID as an API in your Node.JS application.

## Configuration

Assuming you have have added the cli as a dependency in your project,
you can import the [cli](/genaid/reference/api) as follows:

<PackageManagers pkg="genaid" dev />

The API can be imported using imports from **"genaid/api"**.

```js wrap
import { run } from "genaid/api"
```

The imported `api.mjs` wrapper is a tiny, zero dependency loader that
spawns a [Node.JS worker thread](https://nodejs.org/api/worker_threads.html) to run GenAID.

- No pollution of the globals
- No side effects on the process

## `run`

The `run` function wraps the [cli run](/genaid/reference/cli/run) command.

```js wrap
import { run } from "genaid/api"

const results = await run("summarize", ["myfile.txt"])
```

### Environment variables

You can set the environment variables for the GenAID process by passing an object as the `env` field in the options. By default, the worker will inherit `process.env`.

```js wrap
const results = await run("summarize", ["myfile.txt"], {
    env: {
        MY_ENV_VAR: "value",
    },
})
```
