# Azure Foundry with MSAL Authentication

This example demonstrates using Azure OpenAI with Azure CLI authentication.

## Prerequisites
- Azure CLI installed and logged in (`az login`)
- Azure OpenAI resource configured
- AZURE_CREDENTIALS_TYPE=cli in .env

## Code

$`Explain the benefits of using Azure Foundry for enterprise AI applications.`

## Expected Output

The model will explain:
- Managed infrastructure
- Enterprise security
- Integration with Azure services
- Responsible AI features
- Cost management
